Six partner sites, one widget.

Each site is an example from examples/, built for production and served from here. They all run against your local stack, and each one shows off a different part of the widget: token modes, white-labelling, variants, sizing, locales, events and the iframe embed.

Dev wallet

On a local fork, every site's wallet list includes Dev wallet (local fork): a viem local account (an anvil test key) announced through EIP-6963. It signs in the page and sends to the fork, so you can click through without MetaMask. It never appears when the chain isn't a local fork.

Live stack, no hard-coding

Sites read /stack.json, then the web app's /embed/deployment.json for the chain, RPC, API and addresses. Switch the dev chain and they follow it without a rebuild.

Rebuilds

./dev.sh builds each example once and reuses the build until its inputs change (--no-examples skips all of this). Logs: logs/examples.log.

Served by examples/showcase/serve.mjs. Every site is an ordinary production build: vite build, ng build, next build, or a single HTML file.
